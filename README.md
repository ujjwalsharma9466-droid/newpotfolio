Ujjwal Sharma - Personal Portfolio Website

Welcome to the official repository of my personal portfolio website! This project is built to showcase my academic journey, technical skills, projects, and passion for Artificial Intelligence and Machine Learning (AIML).

It features an interactive AI Assistant chatbot widget (powered by Gemini API with smart fallbacks) and a simulated backend contact form leveraging browser localStorage.

🚀 Features

Personalized Profile Showcase: Highlights my background as a B.Tech CSE (AIML) student at KIET Deemed to be University, my Agra roots, and my 88% academic scores in both 10th and 12th grades from Gayatri Public School.

Hobbies & Interests Section: Showcases my passion for playing cricket and listening to music.

AI Assistant Widget: An interactive floating chat widget trained on my professional background to answer visitor inquiries in real-time.

Simulated Backend (Form Submissions): Contact form submissions are saved locally with a dedicated management modal to view or clear stored messages.

Dark / Light Theme Toggle: Seamless appearance switching stored via localStorage.

Fully Responsive & Modern Design: Crafted with HTML5, Tailwind CSS, and FontAwesome icons.

📁 Project Structure

/
├── index.html       # Main HTML structure
├── style.css        # Custom CSS styling and glassmorphism utilities
└── script.js        # JavaScript logic, form backend simulation, and AI assistant integration


🛠️ How to Run Locally

Clone or Download the files into a single project folder.

Ensure index.html, style.css, and script.js are in the same directory.

Open index.html directly in any modern web browser (Chrome, Firefox, Edge, Safari) or use a local development server like Live Server in VS Code.

🌐 Deployment

You can deploy this static portfolio instantly to platforms like:

GitHub Pages

Vercel

Netlify

Simply upload the three files (index.html, style.css, and script.js) to your repository and deploy!
